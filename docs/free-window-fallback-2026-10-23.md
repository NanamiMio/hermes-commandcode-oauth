# 免费窗口结束后的备用模型回退

2026-10-22 18:45 的服务端 403 明确表示 MiniMax M3.1 Flash 免费窗口结束。
原分类把它当作 `auth`，导致 Hermes 停用整个凭据，随后同账号备用模型无法解析。

本次将明确的 `free ... window has ended` 403 归为 `model_not_found`：
不重复请求当前模型、不轮换或停用账号凭据，允许 Hermes 使用已配置的备用链。
普通 401、未知 403 仍走认证处理；不把所有 403 都当成模型问题。
没有自动选择付费模型，也没有重放已经执行的工具操作。

## 本地 CLI 对照

检查本地 `command-code@1.87.1` 的 `dist/cli.mjs`，SHA-256：
`30a67947cf8fcc3348d6d5ad522ba23d5ed10754b81e699ff8b596a4c17e112f`。

- 实际提取并执行 `isRetryableStatus`：401/403 不重试；408/429/500/502/503 可重试。
- `isModelCallRetryable` 与 `completeWithRetry` 排除已识别的套餐窗口限额，
  而不是把它当作普通网络抖动无限重试。窗口限额解析器读取 RATE_LIMITED/429
  和五小时、周、日窗口；这不同于本次 403 的免费活动终止。
- `callModelWithRetry` 对已输出内容的流重启单独计数，并发出 `stream_restart`。
  当前检查到的这个主调用重试循环没有自动切换模型；不要据此推断 CLI 所有路径都无回退。
- `readStreamErrorEvent` 的字符串分支会丢弃顶层 `statusCode`。
  实际执行同一个 403 样例已确认；插件保留状态码，不复制这一行为。
- 不能直接用 CLI 的“是否重试”标志替代 Hermes 的模型/凭据作用域分类。
